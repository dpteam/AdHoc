# Языки интерфейса (i18n)

Обе доски (публичная и админская) переведены через один файл —
`public/assets/js/i18n.js`. Без сборки, без зависимостей, ES5 (работает даже
в старых браузерах на XP).

«Основной набор» — всё, что видно в обычной работе: навигация, карточки статистики,
лобби, группы, события, настройки, каталог, вход в админку, причины выхода, тосты.
Чего нет — автоматически падает в английский (см. «Фолбэк»).

## Как выбирается язык

1. `localStorage['dpt.lang']` — если пользователь уже выбирал;
2. `navigator.languages` / `navigator.language` — регион сводится к нашему коду
   (`pt` → `pt-BR`, `zh-Hans-CN` → `zh-CN`, `uk-UA` → `uk`, …);
3. иначе `en`.

Выбор сохраняется в браузере и не сбрасывается при обновлении страницы.
`<html lang="...">` обновляется, так что работают переносы, шрифты и экранные читалки.

## Переключатель

- в верхней панели обеих досок — компактный `<select id="lang-select">`
  (16 языков, подписи на своём языке: «Русский», «日本語», …);
- в «Настройках» — то же самое с пояснением; смена языка перерисовывает
  модальное окно сразу.

Смена языка не перезагружает страницу: статическая разметка обновляется через
`data-i18n`, а динамические части (списки игр, события, счётчики) — через
`AdHocBoard.langChanged()`.

## Разметка

```html
<span data-i18n="nav.lobby">Lobby</span>              <!-- textContent -->
<h2 data-i18n-title="theme.title">…</h2>              <!-- title="" -->
<input data-i18n-ph="search.ph">                      <!-- placeholder="" -->
<nav data-i18n-aria="nav.sections">…</nav>            <!-- aria-label="" -->
<p data-i18n-html="auth.intro">…</p>                  <!-- innerHTML, для <b>/<code> -->
```

Текст внутри тега — английский: это то, что увидит поисковик и пользователь
до первого запуска скрипта.

## В JS

```js
I18N.t('lobby.players', 3)        // "3 players" / "3 в группе"
I18N.t('stats.onlineSub', '256')  // "of 256" / "из 256"
I18N.setLang('pt-BR')             // переключить и запомнить
I18N.getLang()                    // текущий код
```

Плейсхолдеры — `{0}`, `{1}`. Если ключа нет в выбранном языке, берётся английский,
затем сам ключ (так опечатка видна сразу, а не превращается в пустую строку).

## Как добавить язык

1. В `i18n.js` добавить `var XX = { ... };` — можно скопировать английский блок
   и перевести то, что нужно; недопереведённое честно упадёт в английский.
2. В массив `LANGS` добавить строку:
   ```js
   { code: 'xx', dict: XX, name: 'Xxx', local: 'Xxx' }
   ```
   `code` — наш код (он же уходит в `<html lang>`), `local` — подпись в списке.
3. Если язык имеет региональные варианты, дописать правило в `matchLang()`
   (например `if (base === 'sr') return 'sr';`).
4. Поднять `?v=` у `i18n.js` в `index.html` и `admin.html`.

Список языков в `<select>` строится из `LANGS` автоматически — руками ничего
дописывать не нужно.


Тест проверяет, что `/assets/js/i18n.js` отдаётся, что в нём есть все 16 кодов

пустые состояния и модальные окна без ошибок в консоли.

## Ограничения

- Серверные строки (лог, `status.xml`, `data.json`) не переводятся: это данные,
  а не интерфейс. `Groupless` и коды причин выхода (`peer-closed`) остаются
  латиницей — их читают программы.
- Админский `?` не переводится.
- Числа и даты форматируются браузером (`toLocaleString` не используется,
  чтобы не зависеть от локали ОС) — пробелы в тысячах универсальные.
