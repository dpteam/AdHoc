## Статус реализации (DPT.Agent)

Сделано:

- [x] .NET Framework 4.0 / C# 4, только BCL, сборка стоковым `csc.exe` (`build.cmd`), никаких NuGet/MSBuild.
- [x] Протокол PRO Online / PPSSPP (`SceNetAdhocctl`) по актуальному `proAdhocServer.cpp`:
      LOGIN(144) / CONNECT(9) / DISCONNECT / SCAN / CHAT(65) / PING, ответы CONNECT_BSSID,
      CONNECT(139), DISCONNECT(5), SCAN(15), SCAN_COMPLETE, CHAT(193). См. `docs/PROTOCOL.md`.
- [x] Веб-морда `public/`: VK/FB-2008 (синий градиент, мелкая типографика, блоки) + современные тени,
      скругления, переходы; темы `light` / `dark` / `oled`; Font Awesome + работа без CDN.
- [x] Звуки WebAudio (синтез, без файлов): вход, выход, новая игра, чат, ошибка, потеря/возврат связи;
      вкл/выкл + громкость + выбор событий, всё сохраняется в браузере.
- [x] Удобный список игр с раскрытием: игры → группы → игроки (ник, MAC, IP, время, idle, хост, кик),
      поиск, сортировка, фильтр «только с игроками».
- [x] База игр: 162 названия + 115 crosslink'ов (из PPSSPP/PRO Online), `data/games.json`,
      добавление/правка названия и региона прямо из UI, `/api/reload`.
- [x] Таймауты и уборка: idle-таймаут, жёсткий лимит сессии, автоочистка пустых игр.
- [x] Расширенное логирование протокола через `Trace` (без App.config), один listener,
      `logs/adhoc-YYYYMMDD.log`, ротация, уровни, hex + расшифровка пакетов, без дубля в консоль.
- [x] Динамическая отказоустойчивость: supervisor с backoff, fallback-порты, мягкий режим протокола,
      баны IP, rate limit HTTP, лимиты буферов и параллельных запросов.
- [x] `.git` инициализирован, `user.name = DPT.Agent`, `refs/` и runtime-мусор в `.gitignore`.

Осознанные решения (отличаются от старых наработок в `refs/`):

1. Старый `AdHocPPSSPPServerDotNet` слал LOGIN_ACK и использовал выдуманные опкоды (0x04/0x06/0x0B
   с MAC-заголовками) — с PPSSPP это не работает. Реализован настоящий протокол, ACK на логин
   не отправляется (как в референсе).
2. `HttpListener` заменён на свой HTTP/1.1 поверх `TcpListener`: на Windows он требует admin/URL ACL
   для LAN-префиксов, а на XP ведёт себя иначе. Теперь `netsh` не нужен вообще.
3. Вместо SQLite — свой JSON (`data/games.json`) и свой мини-JSON, чтобы не тащить зависимости.
4. Мягкий режим протокола: странный пакет не убивает сессию, а логируется (диагностика важнее).
